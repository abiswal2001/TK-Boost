Method

How TK-Boost Works

Two phases: discover misconceptions offline, then correct them at query time.

1

Discover Misconceptions

Run the agent on labeled queries, compare to ground truth, and identify recurring mistakes.

2

Generate Knowledge

Convert each misconception into a reusable corrective statement with applicability conditions.

3

Index in TK-Store

Tag knowledge with SQL keywords, tables, columns, and data types for precise retrieval.

4

Correct at Query Time

Retrieve matching knowledge from the SQL draft and apply CTE-level feedback before final output.

Quick Start

terminal 
# Clone and install
git clone https://github.com/abiswal2001/TK-Boost.git
cd TK-Boost && pip install -r requirements.txt

# Run the SQL agent
python src/agents/sql_agent_runner.py \
  --instance-id local066 \
  --jsonl-path data/spider2-lite.jsonl \
  --model azure/gpt-4.1 \
  --out-base outputs/baseline
