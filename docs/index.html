TK-Boost

SQL agent framework for multi-database benchmarks with iterative CTE-based refinement.

SQLite Snowflake BigQuery LLM-Powered

Features

Multi-Database SQLite, Snowflake, and BigQuery with automatic engine detection.
CTE Refiner Iteratively validates and improves each CTE independently.
Predicted Hints LLM-generated table/column predictions guide exploration.
Parallel Execution Batch-process multiple instances concurrently.

Quick Start

git clone https://github.com/cusgadmin/TK-Boost.git
cd TK-Boost
pip install -r requirements.txt

python src/agents/sql_agent_runner.py \
  --instance-id local066 \
  --jsonl-path data/spider2-lite.jsonl \
  --model azure/gpt-4.1 \
  --out-base outputs/baseline

How It Works

The agent receives a natural language question and a database schema. It explores the database, generates candidate SQL using Common Table Expressions, then optionally refines each CTE through an LLM-driven validation loop. Results are evaluated against ground truth for accuracy.
