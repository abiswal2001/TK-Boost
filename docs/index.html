Arming Data Agents with Tribal Knowledge

A bolt-on framework that teaches NL2SQL agents reusable corrective knowledge learned from experience — boosting accuracy on real-world databases.

Shubham Agarwal · Asim Biswal · Sepanta Zeighami · Alvin Cheung · Joseph Gonzalez · Aditya G. Parameswaran

📄 Read Paper 🔗 GitHub ✍️ Blog Post

Overview

TK-Boost is a bolt-on framework for improving NL2SQL reliability on real databases. Instead of only relying on prompt engineering or past query retrieval, TK-Boost learns reusable tribal knowledge: corrective rules derived from real mistakes.

  • Finds recurring SQL/data misconceptions from training examples.
  • Stores them as structured, searchable knowledge.
  • Applies the right checks at refinement time (e.g., CTE-level correction).
  • Works across engines (SQLite today; Snowflake, BigQuery, and Postgres support in code paths).

Quickstart: Build Tribal Knowledge on Your Data

Quickstart should only need translation, knowledge generation, and refinement.

Step 1 — Initialize + translate question to SQL with a ReAct agent

import tkboost
from tkboost import SQLiteExecutor, SQLAgent

tkboost.init(provider="auto", model="azure/gpt-5")

executor = SQLiteExecutor("tkstore/example/Baseball.sqlite")
agent = SQLAgent()

draft = agent.translate(
    question="Compute the average career span in years for baseball players.",
    executor=executor,
    db_name="Baseball",
)

Step 2 — Generate/update tribal knowledge store

store = tkboost.generate(
    example_json="tkstore/example/example.json",  # local007
    store="tkstore/tkstore_example.csv",
    executor=executor,
    debug=True,
)

Step 3 — Refine the same draft using TK (no draft regeneration)

result = tkboost.sql(
    draft=draft["sql"],
    executor=executor,
    store=store,
    db_name="Baseball",
)

Step 4 — Compare agent vs refined outputs (quick quality check)

from pathlib import Path

gold_sql = Path("tkstore/example/gold.sql").read_text(encoding="utf-8")

_, agent_rows = executor.execute(draft["sql"])
_, refined_rows = executor.execute(result["refined_sql"])
_, gold_rows = executor.execute(gold_sql)

print("agent:", agent_rows[:3])
print("refined:", refined_rows[:3])
print("gold:", gold_rows[:3])

Optional — visualize and edit your store

store.visualize(port=8501)

You can pass either example_json (single example) or examples_dir (batch of example folders). In practice, most workflows use examples_dir; example_json is useful for one-off debugging.
