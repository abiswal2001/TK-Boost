Usage

Practical setup and runbook for TK-Boost.

Quickstart (minimal)

This is the minimal end-to-end pattern (using the `local007` example format).

Step 1 — Initialize + translate question to SQL with a ReAct agent

import tkboost
from tkboost import SQLiteExecutor, SQLAgent

tkboost.init(provider="auto", model="azure/gpt-5")

executor = SQLiteExecutor("tkstore/example/Baseball.sqlite")
agent = SQLAgent()

draft = agent.translate(
    question="Compute the average career span in years for baseball players.",
    executor=executor,
    db_name="Baseball",
)

Step 2 — Generate/update tribal knowledge store

store = tkboost.generate(
    example_json="tkstore/example/example.json",  # local007
    store="tkstore/tkstore_example.csv",
    executor=executor,
    debug=True,
)

Step 3 — Refine the same draft using TK (no draft regeneration)

result = tkboost.sql(
    draft=draft["sql"],
    executor=executor,
    store=store,
    db_name="Baseball",
)

Step 4 — Compare agent vs refined outputs (quick quality check)

from pathlib import Path

gold_sql = Path("tkstore/example/gold.sql").read_text(encoding="utf-8")

_, agent_rows = executor.execute(draft["sql"])
_, refined_rows = executor.execute(result["refined_sql"])
_, gold_rows = executor.execute(gold_sql)

print("agent:", agent_rows[:3])
print("refined:", refined_rows[:3])
print("gold:", gold_rows[:3])

Optional — inspect the store dashboard

store.visualize(port=8501)

If your base agent is GPT-5, keep `agent_sql_path` in each training example pointed at that agent's draft SQL. TK-Boost generation/refinement flow stays the same.

Basic environment setup

git clone https://github.com/abiswal2001/TK-Boost.git
cd TK-Boost
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt

`tkboost.sql(...)` and `tkboost.generate(...)` use `litellm`; ensure your chosen provider credentials are set.

Using Spider2 data

Get the Spider2 benchmark package from the official release channels (paper/project page), then place files where TK-Boost expects them.

  • Put instance metadata JSONL at a path like data/spider2-lite.jsonl.
  • Place DB assets under a stable local directory (for example under data/spider2/).
  • For each training example folder, create an example.json that points to your local DB and SQL/result files.

The repo includes working templates/scripts under tkstore/ and scripts/ that show expected file naming.

Using your own data

Create one folder per training example:

my_examples/
  ex_001/
    example.json
    gold.sql
    # optional:
    # execution_query.sql
    # gt_result.csv
    # execution_result.csv
    # db_info.txt
  ex_002/
    example.json
    gold.sql

Minimal `example.json`:

{
  "example_id": "ex_001",
  "db_name": "my_db",
  "engine": "sqlite",
  "question": "Natural language question here",
  "gold_sql_path": "gold.sql"
}

Then generate knowledge in batch:

from tkboost import SQLiteExecutor
import tkboost

tkboost.init(provider="auto")
executor = SQLiteExecutor("/absolute/path/to/my_db.sqlite")

store = tkboost.generate(
    examples_dir="/absolute/path/to/my_examples",
    store="/absolute/path/to/my_tkstore.csv",
    executor=executor,
    debug=True,
)
